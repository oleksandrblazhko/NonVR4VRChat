# NonVR4VRChat - проєкт «Природний інтерфейс керування аватаром у настільному режимі VRChat-середовища для проведення спортивних змагань»

## Опис проєкту

В межах проєкту розроблено програму, призначену для **керування аватаром у середовищі VRChat** без використання VR-шолома та контролерів.

На відміну від традиційного керування за допомогою клавіатури та миші, програма забезпечує взаємодію з аватаром на основі:

- рухів тіла користувача;
- нахилів фітнес-обладнання.

### Розпізнавання рухів тіла

Для розпізнавання положень ключових точок тіла за відеозображенням використовується бібліотека **MediaPipe**.

На основі аналізу рухів **голови та плечей** формуються команди керування:

- поворотом голови аватара;
- поворотом тіла аватара.

### Керування переміщенням

Для керування переміщенням аватара використовуються дані про **нахили фітнес-обладнання**, зокрема балансуючої дошки.

Дані про нахили отримуються за допомогою **акселерометра та гіроскопа смартфона**, закріпленого на обладнанні.

На основі отриманих даних формуються команди переміщення аватара:

- вперед;
- назад;
- вліво;
- вправо.

Це дає змогу імітувати **ходьбу або біг** у віртуальному середовищі.

### Взаємодія з VRChat

Взаємодія з **VRChat** реалізована через **OSC-інтерфейс**.

OSC-повідомлення надсилаються на локальний OSC-сервер, запущений під час роботи VRChat,
та використовуються для:

- керування поворотами голови та тіла аватара;
- передавання команд переміщення аватара;
- емуляції натискання клавіш клавіатури та кнопок миші.

### Результат

Розроблена програма забезпечує керування **поворотами та переміщенням аватара за допомогою природних рухів користувача**.

Програма може використовуватися для реалізації **спортивних змагань у віртуальному середовищі**.

### Особливості встановлення програми в ОС Windows

1) Завантажити Python 3.10
https://www.python.org/ftp/python/3.10.10/python-3.10.10-amd64.exe

2) знаходячись у терміналі GitBash, клонувати репозиторій:
gi clone https://github.com/oleksandrblazhko/NonVR4VRChat.git

3) перейти до каталогу NonVR4VRChat:
cd NonVR4VRChat

4) Створити окреме віртуальне середовище з версією 3.10:
py -3.10 -m venv .venv

5) Активізувати python-середовище:
. .venv/Scripts/activate

6) Встановити бібліотеки:
- py -m pip install --upgrade pip
- py -m pip install -r requirements.txt

7) запустити програму вибору VRChat-світів (приклад шляхів для GitBash):
py ./VRChatApp/main.py
або без необхідності активації
.venv/Scripts/python.exe VRChatApp/main.py

8) запустити програму MediaPipe (приклад шляхів для GitBash):
py MediaPipe/main.py
або
.venv/Scripts/python.exe MediaPipe/main.py

9) запустити програму SmartPhone (приклад шляхів для GitBash):
py SmartPhone/main.py
або
.venv/Scripts/python.exe SmartPhone/main.py

10) після роботи деактивізувати python-середовище (за бажанням):
deactivate
