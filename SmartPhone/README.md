## Налаштування смартфону

Для контролю нахилів смартфона через дані акселерометра необхідно:
1) на смартфон встановити програму phyphox:
- https://phyphox.org/
- https://play.google.com/store/apps/details?id=de.rwth_aachen.phyphox&hl=en
2) обрати Raw Sensors:
- Acceleration with g
3) запустити HTTPS-сервер:
- натиснути кнопку ... (верхній правий куток екрану)
- вибрати "Allow remote access" 
- підтвердити включення серверу - кнопка OK (після система повідомить адресу сервера)
4) натиснути кнопку "Трикутник" (верхня панель), розповши отримання даних від акселерометра

## Налаштування Websocket-сервера

1) запустити програму `main.py`
2) провести калібрування нейтрального розташування смартфона (натисніть `F1` під час роботи програми). Дані калібрування будуть збережені в `config.json` та автоматично завантажуватимуться при наступних запусках.

## Особливості налаштування Websocket-клієнта

### Адаптація існуючих програм
Каталог містить приклади Scratch-програм (sb3-розширення), які клоновано з офіційного відкритого Scratch-репозиторія.
Для адаптації Scratch-програм під керування через нахили смартфону використано середовище TurboWarp:
1) Web - https://turbowarp.org/
2) Desktop - https://desktop.turbowarp.org/
Для обробки даних з Websocket-сервера у Scratch-програмах виконано наступні зміни:
- підключено WebSocket-розширення;
- створено Controller-спрайт, який встановлює значення змінної contr_direction (left, right, up, down)
- у відповідних спрайтах додано контроль нахилу через перевірку змінної contr_direction

Сервер передає дані accX,accY, враховуючи клаcичне вертикальне розташування смартфона.
Якщо смартфон розташувати горизонтально для зручного використання у більшості механоприладах,
тоді у програмах візуалізації необхідно змінити призначення: 
- для координат: x := accY, y := accX.
- для кутів нахілу: angle_x := angle_y, angle_y := angle_x

### Особливості адаптації
Для ігор, де алгоритм враховує тривалість натискання клавіші, наприклад, у грі "7-Lightcube-Platformer-SmartPhone.sb3",
коли тривалість натискання призводить до збільшення висоти стрибку персонажа, поточний алгоритм може бути неоптимальним через фізичну затримку.
Запропоновано ввести ще один стан змінної contr_direction = null, який формується після завершення обробки сигналу натискання клавіші у відповідних спрайтах.
Controller-спрайт контролює цю зміну, не даючи можливість повторного спрацьовування події натискання та вимагаючи повернутися дол нейтрального положення смартфона.
Такий алгоритм забезпечує дискретизацію, яка в свою чергу гарантує вчасний контроль переміщення.

## Запуск програми

Програма `main.py` підтримує наступні параметри командного рядка для керування її поведінкою:

*   `--osc`: Активує режим надсилання OSC (Open Sound Control) команд на основі даних акселерометра. Для роботи цього режиму потрібна встановлена бібліотека `python-osc`. OSC-команди надсилаються на `127.0.0.1:9000` за адресами `/input/MoveForward`, `/input/MoveBackward`, `/input/MoveLeft`, `/input/MoveRight`, `/input/Run` з булевим значенням `True` або `False`. Команда `/input/Run` активується при значному нахилі вперед або назад, перевищуючи `run_threshold` (див. `config.json`).
*   `--websocket`: Активує WebSocket сервер на `ws://localhost:8767`. Цей сервер транслює дані акселерометра підключеним клієнтам. Якщо цей параметр не вказано, WebSocket сервер не запускається.

**Конфігураційний файл `config.json`:**

`config.json` використовується для зберігання налаштувань, таких як IP-адреса сервера, поріг для команди "Run" та режим налагодження.
Приклад `config.json`:
```json
{
  "server_ip": "192.168.0.104",
  "run_threshold": 1.5,
  "debug": false,
  "delta_accX": 0.0,
  "delta_accY": 0.0
}
```
*   `server_ip`: IP-адреса HTTP-сервера phyphox.
*   `run_threshold`: Поріг для активації команди `/input/Run`.
*   `debug`: Якщо `true`, у консоль виводитимуться всі надіслані OSC-команди.
*   `delta_accX`, `delta_accY`: Зміщення для калібрування акселерометра, зберігаються автоматично після калібрування.

**Приклади використання:**

*   Запуск з надсиланням OSC команд:
    ```bash
    python main.py --osc
    ```
*   Запуск WebSocket серверу:
    ```bash
    python main.py --websocket
    ```
*   Запуск з усіма режимами:
    ```bash    
    python main.py --websocket --osc
    ```

**Клавіші керування:**

*   `F1`: Калібрування стану спокою акселерометра.
*   `Esc`: Завершення роботи програми.
