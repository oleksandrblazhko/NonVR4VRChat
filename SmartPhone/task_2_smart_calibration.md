# Persona 
Зараз програма SmartPhone бере з файлу конфігурації SmartPhone\config.json
опис "osc_bindings".

Але існують різні приклади особливостей налаштування смартфона (приклади у файлі SmartPhone\README.md ),
коли користувач повинен змінювати опис.

Пропонується додати режим автоматизованого налаштування параметрів як режим smart-калібрування

# Tasks

1) режим smart-калібрування запускається через кнопку F2

2) програма пропонує користувачу послідовно виконати дії:
- зафіксувати смартфон у нейтральному стані
- зафіксувати смартфон у крайньому положені під час руху вперед
- зафіксувати смартфон у крайньому положені під час руху назад
- зафіксувати смартфон у крайньому положені під час руху вліво
- зафіксувати смартфон у крайньому положені під час руху вправо

3) під час кожної дії програма впродовж 3-х секунд накопичує данні для x-y-z-вісей

4) для кожного стану програма порівнює x-y-z-вісі між собою для визначення вісей, які максимально змінюють свої дані

5) програмає надає рекомендації щодо встановлення значень "osc_bindings"
