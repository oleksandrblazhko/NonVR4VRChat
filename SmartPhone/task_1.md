Зараз програма SmartPhone оброблює значення x,y-вісей для виконання OSC-команд:
"/input/MoveForward" - вісь X
"/input/MoveBackward" - вісь X
"/input/MoveLeft" - вісь Y
"/input/MoveRight" вісь Y
"/input/Run" вісь X, вісь Y

В подальшому планується змінювати звязок між вісями та командами,
тому треба винести з програмного коду такий звязок до конфігураційного файлу.

Пропоную:
1) додати в конфігураційний файл елементи, які будуть адаптивно визначати звязок між вісями та командами, наприклад:
{
"osc_command" : "MoveForward",
"axis" : "X"
}

2) оновити алгоритм роботи програми, який:
- читає конфігурацію
- змінює вісі для перевірку значень та виконання команд

Зараз параметр thresholds використоває незрозумілі для використувача значення.
Користувачу більш зрозумілі значення кута нахилу.
Експерименти показали наступні перетворення значень вісей у кути нахилу:
- для вісі X:
    - x=abs(0) - 0 градусів
    - x=abs(9.8) - 90 градусів
- для вісі Y:
    - y=abs(0) - 0 градусів
    - y=abs(9.8) - 90 градусів
- для вісі Z:
    - z=abs(9.8) - 0 градусів
    - z=abs(0) - 90 градусів

Задачі:
1) змінити значення вісей на кути в конфігураційному файлі
2) в програмі реалізувати перотворення з кутів на значення вісей.

Раніше у стані спокою смартфон розташовувався горизонтально,
наприклад, стан спокою визначається значеннями: 
  "delta_accX": -0.02952323209446154,
  "delta_accY": 0.07237477213692307,
  "delta_accZ": 9.840813223076923,

Для надсилання OSC-команд використовувалися такі рухи смартфона:
- нахил вліво-вправо - зміна вісі Y
- нахил вперед-назад - зміна вісі X

Тепер було змінено розташування смартфону - у стані спокою він розташовується вертикально, 
наприклад, стан спокою визначається значеннями: 
"delta_accX": -0.1271443429843517,
"delta_accY": 9.589331666169896,
"delta_accZ": 1.9736108915052162

Тепер для надсилання OSC-команд необхідно використовувати такі рухи смартфона:
- нахил вліво-вправо - зміна вісі X
- нахил вперед-назад - зміна вісі Z

Поточна конфігурація вже це враховуває.
Але OSC-команди не надсилаються.
Чому ?
Можливо, програмний код враховував горизонтальне розташування смартфона.
